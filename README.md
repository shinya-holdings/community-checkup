# 次に声をかける3人

コミュニティの発言ログから、**伸びしろのある人**と**離れかけている人**を見つけるツールです。

HTMLファイル1つで動きます。インストールもアカウント登録も要りません。

**→ [ツールを開く](https://example.github.io/community-checkup/)**（公開後にURLを差し替える）

---

## なぜ作ったか

Discordで6ヶ月かけて5,000人の方に参加していただきました。
NFTのセールが延期になり、1週間で500人が離れていきました。

集まるのは1日28人。離れるのは1日71人。
**崩れる速度は、集まる速度の2.5倍でした。**

残ったのは1,000人。でも振り返ると、最初から話してくれていたのは1,000人だった。
いなくなったのではなく、**最初から届いていなかった**んです。

当時「今日チャット流れてないな」としか思っていませんでした。
数字を数えたのは、後になってからです。

このツールは、そのとき見ておくべきだったものを出します。

---

## 何が出るか

診断して終わりではなく、**誰に何をするか**まで出します。

| 出るもの | 判定 |
|---|---|
| **次に声をかける3人** | 発言はあるが中心にはいない。他の人とやり取りしていて、複数の日に顔を出している人 |
| **中核メンバー** | いま支えてくれている人。抜けると目に見えて盛り上がらなくなる |
| **発言が止まった人** | 2回以上話していたのに、途中から途切れた人。離脱の予兆 |
| **一度きりで戻っていない人** | 最初の1回に返事がつかなかった可能性が高い |
| **まだ一度も話していない人** | 人数（メンバー数を入力した場合） |

あわせて、発言の中身から**その人が何をしている人か**を推定します。
「話題を出す人」「答える人」「迎える人」「繋ぐ人」「場を温める人」「頼られている人」の6種類です。

## 使い方

1. コミュニティの発言ログを読み込む（ドラッグ＆ドロップ、または貼り付け）
2. **運営・コミュニティマネージャーにチェックを入れて外す**
3. 分析する

### 対応している形式

| 形式 | 例 |
|---|---|
| `.txt` | Discordの画面からコピーして保存したもの |
| `.docx` | Wordに貼り付けたもの |
| `.csv` | 投稿者・日時・本文の列があるもの |
| `.json` | DiscordChatExporter の書き出し |
| `.html` | 同上 |
| 貼り付け | Discordの画面から直接コピー |

### 運営を外してください

運営やコミュニティマネージャーは、投稿するのが仕事です。
外さないまま数えると必ず中核に入り、「一部に偏っている」という結果になります。

**運営を外すと、絵が変わります。**
実際に試したところ、外す前は「声をかける候補」だった2人が、外した後は中核に上がりました。
運営の陰に隠れて、**メンバーの中の主力を見落としていた**わけです。

「運営」「公式」「管理」「オーナー」「マネージャー」などを含む名前は、最初から自動でチェックが入ります。

## プライバシーについて

- **すべてブラウザの中だけで計算しています。** ログはどこにも送信されず、保存もされません
- サーバーもデータベースもありません。ファイルを開いた時点で、通信は発生しません
- **生成AIにログを送ってはいません。** 役割の推定も、ブラウザ内の文字列処理で行っています
- 書き出す画像に**個人名は含めません**
- 画面のスクリーンショットを共有する場合は「名前を伏せて表示する」を使ってください

---

## 精度について

役割の推定は、日本語の言い回しと会話の並びから判定しています。
**あくまで傾向で、外れることもあります。** 最終的にはご自身の目で確かめてください。

判定がおかしいと感じたら、[Issues](../../issues) で教えてください。
実例をもとにパターンを足していきます。
